— WatchLLM Architectural Guideline
01
Deterministic Guardrails. Enforcement should never rely on non-deterministic model outputs. Security rules require absolute binary clarity.
02
Air-Gapped Analysis. Static AST inspection and policy checks compile and run locally without requiring remote network roundtrips.
03
Auditable Telemetry. Execution traces and architectural state changes are saved to immutable SQLite ledgers for full replayability.
04
Explicit Policy Rules. Replace probabilistic guesswork with precise structural checks at the compiler AST boundary.
