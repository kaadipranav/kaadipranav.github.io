WHO IS KAADZ?

A systems engineer who believes software infrastructure should be boring, predictable, and auditable — not a house of probabilistic cards.

🛡️

BUILDING WATCHLLM

Runtime governance infrastructure for autonomous coding agents. 12 interconnected components — kernel, runtime, schemas, orchestrator, memory (klyd), observability (replay), adversarial testing, benchmarks, VS Code extension, and more. Python. Rust. TypeScript. Wasm.

🧠

PHILOSOPHY

Infrastructure must be deterministic. No API keys. No cloud dependency. No ML inference in the enforcement path. Same input = same output. Always. If your guardrails are probabilistic, they aren't guardrails — they're suggestions. Suggestions don't stop $47,000 crypto arbitrage bots in Minsk.

🔧

STACK

Python for the kernel (Tree-sitter AST analysis). Rust + Wasm for the runtime (zero-GC, cross-platform). TypeScript for VS Code extension and replay UI. SQLite for architectural memory (klyd). Shell for CI/CD. Everything compiles offline. Everything is auditable.

⚡️

"THE ONLY JOBS I'LL HAVE ARE CRON JOBS"

Automation is the point. WatchLLM is a cron job for your codebase — continuously intercepting, continuously enforcing, never sleeping. Zero human in the loop for the enforcement path. Human in the loop for the policy. That's the architecture.
