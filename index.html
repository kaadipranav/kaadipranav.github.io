01 // CORE ARCHITECTURE
GOVERNANCE
PRIMITIVES

Infrastructure requires predictable execution paths. The WatchLLM governance stack enforces structural rules before code mutations are committed.

01
DETERMINISTIC ENFORCEMENT
Guardrails operate without LLM inference overhead in the execution critical path. Identical code inputs produce strictly identical policy evaluations every time.
02
WATCHLLM MONOREPO
Composed of 12 modular units including AST tree-sitter interceptors, zero-GC WASM policy runners, decision schema validators, and execution replay telemetry.
03
AIR-GAPPED INTERCEPTION
Runs entirely offline without cloud network roundtrips. Integrates directly into developer local environments, IDE extensions, and automated CI pipelines.
04
ARCHITECTURAL MEMORY
SQLite-backed decision harness (klyd) maintaining structured, replayable state records for autonomous agentic operations.

AXIOMS
"A GUARDRAIL THAT IS PROBABILISTIC IS MERELY A SUGGESTION."
— WatchLLM Architectural Standard
01
Binary Safety Boundaries. Critical enforcement paths must produce absolute pass/fail outcomes, never statistical likelihoods.
02
Static AST Interception. Policy checks run at the syntax tree level using Tree-sitter before code changes reach disk or git state.
03
Auditable Replay Logs. Every governance decision is recorded in an immutable ledger for historical inspection and replay.
04
Local-First Runtime. Everything compiles to air-gapped WASM targets to run inside local editors and local CI runners seamlessly.
